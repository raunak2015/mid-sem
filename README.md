
# Mid-Semester MCQ Platform

A comprehensive MCQ examination platform built with HTML, CSS, and JavaScript.

## Features
- **Multi-Subject Support**: Switch between React and C++ quizzes.
- **Fair Exam Logic**: Balanced answer distribution (A, B, C, D sequence) to prevent guessing patterns.
- **Dynamic Progress Tracking**: Real-time progress and scoring.
- **Result Analysis**: Detailed breakdown of performance at the end of the quiz.

## Subjects
- **React**: 200+ questions covering basics to advanced hooks and state management.
- **C++**: 300+ questions covering Basics, OOPs, Pointers, and STL.

## Balanced Answers
The questions have been updated to ensure that the correct answers are distributed evenly across all options (A, B, C, and D) in a sequential manner, making the test more robust against simple guesswork.
